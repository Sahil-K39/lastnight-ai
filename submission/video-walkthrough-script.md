# 5-10 Minute Video Walkthrough Script

## Recommended Length

Aim for 6-7 minutes. Keep it direct and show the working product.

## 0:00-0:30 — Intro

```text
Hi, I am Sahil, and this is LastNight AI, my project for the OpenAI x Outskill AI Builders Hackathon. The hackathon is a shipping competition, so I focused on building a working AI product, not just a pitch.
```

## 0:30-1:10 — Problem

```text
The problem is simple: many students start studying the night before an exam. They have syllabus PDFs, PYQs, notes, and lecture files, but they do not know what to study first. Generic AI answers are often too long and not optimized for exam survival.
```

## 1:10-2:30 — Product Flow

Show the landing page, pricing, and start flow.

```text
LastNight AI lets a student enter a subject, upload study material, choose how much time is left, and generate a structured exam survival kit. I also added student-friendly INR pricing at ₹149 per month.
```

## 2:30-4:40 — Live Demo

Use this demo path:

1. Click **Start Preparing**.
2. Enter `Operating Systems`.
3. Upload or stage a sample PYQ/syllabus/notes file.
4. Select `3 Hours`.
5. Run the AI agent.
6. Show the results dashboard.

Say:

```text
The output is not just a chat response. The backend returns structured JSON fields like exam strategy, PYQ pattern analysis, unit-wise importance, high-priority topics, important questions, revision notes, viva questions, quiz, summary, and a study plan.
```

## 4:40-5:40 — Tech Stack

```text
The web app is built with React, Vite, TypeScript, Tailwind CSS, and Three.js. The backend is Express. The AI provider can be Gemini Flash for cloud demo mode or Ollama for local privacy-first mode. I also built a Flutter mobile app path for Android and iOS using the same backend schema.
```

## 5:40-6:30 — Codex Usage

```text
I used Codex throughout the build: project review, bug fixing, UI improvement, cinematic design, web and Flutter sync, login/profile/PYQ upload, provider switching from paid OpenAI API to Gemini and Ollama, security checks, GitHub prep, and final submission assets.
```

## 6:30-7:00 — Closing

```text
LastNight AI is built for students who have hours, not weeks. It turns messy exam material into a practical study plan they can use immediately. Thank you.
```
